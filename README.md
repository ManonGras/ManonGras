### Featured projects

#### [TFT Analytics](https://github.com/ManonGras/TFT_analytics): data pipeline & ML *(personal project)*

Ongoing data pipeline that ingests, cleans, and models competitive match data from the Riot Games API to predict final placement in Teamfight Tactics.

- Riot API client, SQLAlchemy schema, ingestion across all ranked tiers, with a cleaning step to filter out bots/non-player entities (audited down to single mislabeled records among 314k+ participants)
- Placement-prediction model with SHAP interpretability, plus clustering of team comps into archetypes with timing/power-curve analysis
- Date-based train/test split to avoid leakage, set-aware paths for multi-version support
- Unit tests running in CI (GitHub Actions); actively maintained, currently migrating Set 17 → Set 18

`Python`, `SQLAlchemy`, `pandas`, `scikit-learn`, `SHAP`, `pytest`, `GitHub Actions`

#### [Worms-like Game](https://github.com/ManonGras/Worms-likeGame): software architecture & testing *(team project, 6 people)*

2D artillery game (Worms clone) built from scratch in Java over a 7-sprint Agile cycle (OOP & Project Management coursework). Led cross-cutting technical work, CI/CD, testing, refactoring.

- Strict MVC architecture (CI-verified), GUI + CLI views sharing one model; weapon system via composition/polymorphism
- Custom physics engine, destructible terrain, procedural Bézier map generation
- Network multiplayer (TCP server, lobby, chat, snapshot sync), plus local modes
- Save/load with AES-256-GCM encryption and format auto-detection
- 800+ tests (JUnit 5, Mockito, >80% coverage); 6-stage GitLab CI/CD pipeline

`Java 17`, `Swing/AWT`, `Gson`, `JUnit 5`, `Mockito`, `JaCoCo`, `GitLab CI/CD`
